# program/

The owner's description of the building's program and of what the model lacks: authored room
by room, first in the viewer's PROGRAM window (2026-11-05 and 06, since removed), since then by
chat with the room number, applied with dated scripts in `scripts/` that name their source.
Served read-only to the viewer at `/program/*`. Nothing here is read from or written to
`exports/`; the export stays as Revit wrote it.

- `rooms.json`: one entry per Revit room id: level, number, area, name (optional: the use
  stands in), use, access (`campus_class`, `arch_only`, `arch_class`, `arch_all`, `professor`,
  `staff`, `bookable`, `none`), hours (`business` or `always`), who, notes, status (`done` or
  `flagged`) with a reason, dates and source. A rule applied from a general remark is marked
  `access_inferred` until confirmed. Rooms that have been through the object pass also carry
  `activities` (what pulls people in and how the room is arranged for it; `pending` names the
  parameters still to come) and `objects: "program/objects.json"`.
- `edits.json`: corrections to the model, keyed by Revit element id with a reason each (an
  added door names its host wall); `scripts/rasterise.py` applies them to the tiles and marks
  an inferred position.
- `affordances.json`: the catalogue of object kinds, modelled or not, and what an agent does
  with each (verb, posture, people, minutes), whether it moves, what it needs. `inferred: true`
  marks an entry filled from general use, to confirm.
- `objects.json`: objects the building has and the model lacks, added per room with a
  placement rule (`on: opaque_walls`; `wall` + `mount: high`; `ceiling` + `faces`), a reason, a
  source and `inferred_position: true`; the rasteriser places them from the room's walls and
  the pixel views draw them with amber marks. Also the owner's rules for a room's modelled
  pieces (movable, casters, stackable).
- `simulation.json`: the simulation's parameters (the elevator's capacity, timings and control,
  walking and stair speeds, how a trip picks stairs or lift, the test agents), every number
  marked `inferred` until confirmed; read by the viewer on START.
- `TODO.md`: regenerated by `scripts/program_todo.py`: flagged rooms, rooms without an access
  rule or an operation, inferred rules, inferred object positions, pending activities and
  catalogue kinds to confirm.
- `rooms.before-chat-2026-11-06.json`: the file as it was before the first chat script.
